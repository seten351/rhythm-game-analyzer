# 楽曲ジャケットの出典

2026-10-04、ユーザーの「このサイトから各曲の画像を取得して配置し、コミット・pushする」という指示に基づき、[BanG Dream! Our Notes攻略 Wiki*「楽曲一覧」](https://wikiwiki.jp/on_database/%E6%A5%BD%E6%9B%B2%E4%B8%80%E8%A6%A7)に掲載された85曲の画像を取得した。

- 対応表: [Resources/Artwork/manifest.json](../Sources/OurNotesApp/Resources/Artwork/manifest.json)。各曲の永続的なArtworkKey、取得画像URL、詳細ページURL、掲載ファイル名、取得日、元画像と変換後PNGのSHA-256を記録している。
- 画像: 同じディレクトリのPNG。ArtworkKeyのSHA-256をファイル名に使う。WebP／JPEGをImageIOで復号し、向きを適用して最大辺512pxのPNGへピクセルだけを再エンコードした。装飾の追加や内容の改変はしていない。
- 照合: 掲載名・詳細ページとカタログを照合し、Symbolのローマ数字・記号表記差を既存の正規化規則で扱った。3件の既存sample-song IDもそのまま保持する。

画像の権利は各権利者に帰属する。Wikiの掲載画像について明示的な再配布ライセンスは確認できておらず、出典の記録は権利者からの許諾を表すものではない。アプリの独自制作画像としては扱わない。

アプリは同梱画像をオフラインで読み込む。手動で登録した画像を優先し、「既定の画像に戻す」で同梱画像に戻る。ユーザーの選択画像・プレイ記録・ローカル索引はGitへ含めない。マスター更新、画像保存、キャッシュ・復旧／回収の境界は[ブランドモーションと楽曲画像](BrandMotionArtwork.md)を参照。
