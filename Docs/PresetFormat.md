# 解析プリセット v1

実例は `Sources/OurNotesApp/Resources/our-notes-v1.json`。アプリの「環境・プリセット」でローカルJSONを確認して更新します。

- `formatVersion: 1`、固定の`id`と`gameId`、正の整数`version`を持ちます。変更時は版番号を増やします。既存履歴の版番号は書き換えません。
- 試作版のパーサーは`parserId: "our-notes-v1"`。他タイトルは別の読取定義と専用パーサーを追加します。JSONから任意コードは実行しません。
- `regions`は画像左上原点の正規化座標`x/y/width/height`。向き補正後の画像に適用します。
- `aspectRatio`、`aspectTolerance`、`confidenceThreshold`を持ちます。未知の配置は自動登録しません。
- `timing: null`はそのプリセットに調整仕様がない状態です。アワーノーツの旧プリセットではユーザー確認済みの同梱仕様にフォールバックします。小数桁や54ms表示からミリ秒への換算・仕様推定はしません。

同梱プリセットの`version: 2`には、2026-10-02にユーザーがゲーム画面で確認した仕様を追加しています。formatVersion・parserId・OCR領域は従来どおりです。

```json
"timing": {
  "parameter": "ノーツタイミング",
  "unit": "ゲーム内単位",
  "step": 0.01,
  "minimum": -3,
  "maximum": 3,
  "slowCorrectionDirection": 1
}
```

`slowCorrectionDirection`はSLOW優勢を改善する方向です。+1なら設定値を増やし、-1なら減らします。刻みは正、最小値は最大値未満、対象はノーツタイミングです。譜面位置を同時調整しません。

タイミング候補は現在の環境IDと全設定に一致する確認済み履歴から、譜面ごとに`orderDate`の新しい順で最大10プレイを選びます。同時刻はUUID文字列の昇順です。この履歴を一度選んでから全体とプレイ時レベル別に分けます。アワーノーツ固定端末ポリシーでは端末の既知別名・旧履歴の空欄を許容し、音声出力と条件メモをまとめます。厳格ポリシーでは端末・音声出力・条件も照合します。

候補には異なる3曲以上（同一曲の別譜面は1曲）とP＋G詳細500件以上が必要です。各曲内の詳細件数で偏りを計算し、曲ごとの偏りを曲あたり同じ重みで平均します。その絶対値が10%以上で、詳細件数で加重した偏りも同じ方向、さらに3分の2以上の曲が同方向の場合に1ステップだけ提案します。必要条件を満たしたレベル帯同士で方向が逆、またはレベル帯の候補が全体候補と逆方向の場合は、全体候補を保留します。低データのレベル帯は全体を止めません。レベル不明は全体に含みますが、レベル別の数値候補は出しません。最適値や遅延ミリ秒の断定はしません。

固定値の新規入力は範囲と変更刻みを検証します。調整候補の表示は保存操作ではありません。詳細は[固定タイミングの仕様](Timing.md)を参照してください。
